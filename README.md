# 7 Miles support site

This directory is a static, dependency-free GitHub Pages package for the URLs
currently embedded in the iOS app:

- `https://socrim2026-ops.github.io/7-miles-support/`
- `https://socrim2026-ops.github.io/7-miles-support/privacy/`
- `https://socrim2026-ops.github.io/7-miles-support/terms/`

Publish the contents of this directory at the root of the public
`socrim2026-ops/7-miles-support` repository, or change the URLs in the app and
App Store metadata together. Do not publish to a different path while leaving the
embedded links unchanged.

The public developer identity is `Mirco Schoepf` and the support address is
`socrim2026@gmail.com`. These values match the release signing identity and the
project's configured developer account as audited on August 23, 2026. If either
changes, update all three HTML pages before publishing a new release.

The pages contain no scripts, analytics, forms, cookies set by site code, or
external font/image dependencies. GitHub Pages may still process standard server
logs under GitHub’s policies.
